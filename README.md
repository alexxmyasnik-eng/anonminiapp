# AnonPeak — Mini App (Frontend)

Telegram Mini App, один файл `index.html`.

## Deploy

Загрузи `index.html` на GitHub Pages:
1. Создай репозиторий → Settings → Pages → Deploy from branch `main`
2. В BotFather: `/setmenubutton` → укажи `https://твой-юзер.github.io/репо/`

## Переменные

В `index.html` найди строку `API_BASE` и укажи URL твоего Render-сервиса:
```js
const API_BASE = 'https://твой-api.onrender.com';
```
